AI Meeting Intelligence

An AI-powered Meeting Intelligence web application that allows users to upload meeting transcripts (TXT, PDF, DOCX), automatically generate AI summaries, extract action items, and track task completion in real time.

Features

Secure JWT Authentication (Login/Register)

Upload TXT, PDF & DOCX meeting files

AI-generated meeting summary

Automatic action item extraction

Mark action items as completed

Real-time status updates using SignalR

Analytics dashboard with meeting statistics

PDF report download

Responsive modern UI built with Material UI
